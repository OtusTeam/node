# 02 — child_process.exec

`exec` запускает команду в shell и буферизует весь stdout/stderr.
Удобно для коротких команд; для больших объёмов данных лучше `spawn`.

## Запуск

```bash
npm run case:02
# или
node cases/02-exec
```

## На что смотреть

- Аргументы дочернего скрипта: `--user_id=100`.
- Результат приходит одним куском в callback (`stdout`).
- Буфер по умолчанию ограничен (~200 KB) — это ограничение `exec`.
