# 09 — cluster

Горизонтальное масштабирование на одной машине: master форкает worker-процессы
(обычно по числу CPU) и балансирует входящие соединения.

## Запуск

```bash
npm run case:09
# или
node cases/09-cluster
```

Нагрузка:

```bash
npm run stress -- --path /fast
```

## На что смотреть

- В логах несколько `pid` — по одному на worker.
- Throughput `/fast` обычно выше, чем у одного процесса из кейса `07`.
- Упавший worker поднимается снова (`cluster.on('exit')`).
- Это масштабирование **всего** HTTP-сервера, не точечный offload одной задачи.
