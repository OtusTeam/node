# 03 — child_process.spawn

`spawn` стримит stdout/stderr чанками, без накопления всего вывода в память.
Подходит для длинных процессов и больших логов.

## Запуск

```bash
npm run case:03
# или
node cases/03-spawn
```

## На что смотреть

- Данные приходят событиями `data`, а не одним буфером.
- Нет shell по умолчанию (безопаснее, чем `exec`).
- Код выхода — в событии `close`.
