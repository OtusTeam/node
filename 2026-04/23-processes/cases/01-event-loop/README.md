# 01 — Event Loop

Показать, что синхронная тяжёлая работа блокирует event loop: таймеры и I/O ждут.

## Запуск

```bash
npm run case:01
# или
node cases/01-event-loop
```

## На что смотреть

- `setTimeout(0)` должен сработать «сразу», но печатается только после тяжёлого цикла.
- Вывод: сначала `heavy done`, потом `timeout`.
